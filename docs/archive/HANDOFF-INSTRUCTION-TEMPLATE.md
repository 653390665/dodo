# 新项目接力模板

下面这段是通用版模板。以后你在其他项目里也可以直接照着改路径使用。

```text
请先读取并总结以下项目归档，再继续协助我开发：

1. <项目路径>/docs/archive/<最新 development archive 文件名>
2. <项目路径>/docs/archive/<最新 chat log 文件名>

要求：
- 用中文回复
- 先总结当前开发状态、已完成工作、未完成工作、关键风险
- 再给出你建议的下一步优先级
- 如果我要继续开发，请直接基于这些归档接着做，不要让我重复解释背景
- 代码仓库路径是：<项目路径>
```

## 更强一点的接手版

```text
你现在接手一个本地项目，请先完整读取以下归档并建立上下文：

- <项目路径>/docs/archive/<最新 development archive 文件名>
- <项目路径>/docs/archive/<最新 chat log 文件名>

工作要求：
- 用中文回复
- 先总结项目现状、技术栈、主链路、已完成功能、当前问题和推荐下一步
- 回答时引用关键文件路径
- 如果后续需要改代码，默认在 <项目路径> 内工作
- 不要重新做无关探索，优先基于归档继续推进
```

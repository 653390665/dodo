# 012 — 文风与正文货架：分类消重与适合度呈现

> 生成：2026-09-08。来源：用户 PM 诊断（文风与正文 73 张卡"分类不清/与创作流程重复/评分无区分度"）。
> 方法：一手数据实测（目录全量聚类 + 创作流程步骤对照 + 评分分布），非主观印象。

## 诊断（实测数据）

73 张卡实际构成 = **31 个系列/孤岛** 平铺在一个页签里：

| 问题 | 实测证据 |
|---|---|
| **分类错位** | "文风与正文"页签里混入了**大纲生成×5、世界观生成×2、角色生成×2、脑洞生成×3、简介生成×1、拆书器×1**——大半不是"文风与正文"，是整套创作前期能力 |
| **与创作流程重复** | ①【小飞鸡】爆款短篇第一步/第二步/第三步 = 三步流程拆成 3 张单卡；②【风华出品】私有化流程 1-6 = **整套创作流程包装成单卡**上架；③脑洞生成（天马/猫头鹰）≈ 流程步骤"脑洞灵感闪耀" ≈ 能力包"脑洞与角色构建包"——同一功能**三处入口** |
| **系列未折叠** | 【风华出品】25 张（含 11 张题材大类模板 + 私有化流程 + 正文/审稿/仿写）、lwl 13 张、小飞鸡 6 张——同系列卡片平铺刷屏 |
| **评分无区分度** | 冷启动证据分：≥80 仅 10 张，**74-79 挤了 32 张**，<74 有 31 张。且它是"证据分"不是"适合度"——用户无法判断哪张适合自己的题材/平台/当前阶段 |

## 根因（PM 视角）

1. 011 Phase 3 按 placementTier 把目录**原样平铺**上货架，把目录侧的整理债直接带进了 UI（投影只做了运行时过滤，没做分类与消重）；
2. 卡与创作流程步骤**同源不同包装**（广场私有流程整包/分步卡 vs 流程页签的结构化流程），缺"已含于流程"的消重标记；
3. 评分是**卖方视角**（资产证据），缺**买方视角**（与当前作品题材/平台/阶段的适合度）。

## 修复方案（四项，按优先级）

### P1 二级分类（组内分组，纯前端规则聚类）
"文风与正文"页签内按功能关键词（title/goal 匹配）分为五组，组头计数：
`正文润色与文风`（7+）、`故事生成`（脑洞/世界观/角色/事件 ≈8）、`大纲与简介`（≈6）、`题材模板`（11）、`拆书与仿写`（≈3）+ `系列`分组（风华/lwl/小飞鸡/天马…折叠为系列头）。
规则落在 `getOptionalStyleAssets()` 旁新增 `getStyleShelfGroups(assets)` 纯函数，可测试。

### P2 流程消重标记
与 SKILL_SERIES_FLOWS 步骤 assetId 重合（square-183/76、private-163 等）或语义重合（私有化流程×N、分步卡）的卡：
徽章「已含于创作流程」+ 默认折叠进"系列"分组；卡片详情提供"查看对应流程"跳转。
**不删除资产**——独立使用仍合法，只是不再与流程并排竞争注意力。

### P3 评分呈现改造
"冷启动证据 86"（卖方证据）→ 组内排序键保留，但卡面主展示改为**适合度信号**：
题材标签 ∩ 当前作品 tags 命中数（后端已有 genreTags/inferNovelGovernanceProfile 可复用），无命中则显示"通用"。
排序：组内按（题材命中数， score）双键。

### P4 系列折叠
同前缀系列（≥3 张）默认折叠为系列头（【风华出品】25、【小飞鸡】6、lwl 13），展开看单卡。

## 涉及文件

- `src/lib/capability-governance.ts`（getStyleShelfGroups + 适合度匹配纯函数）

## 验证

- 分组函数：73 张全部归组无遗漏；五组 + 系列组计数与手数一致
- 消重：小飞鸡三步/风华私有化流程/与流程重合卡全部带「已含于创作流程」徽章
- 全量前端测试绿

## 边界

- 不删除/不改造任何目录资产数据；纯展示层分类与标记
- 适合度匹配首版用标题/goal 关键词规则，不上模型

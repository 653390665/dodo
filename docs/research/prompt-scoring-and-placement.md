# Prompt Scoring And Product Placement

日期：2026-07-03
使用技能：`product-strategy-session`、`prioritization-advisor`、`roadmap-planning`

## 核心结论

提示词评分和产品放置必须分开。

- **评分**回答：这条提示词好不好，强在哪里，风险在哪里。
- **放置**回答：它应该默认内置、Agent 引导触发、用户选配、付费增强，还是只做研究。

不能用“分数高”直接决定“给用户多一个可选项”。提示词越多，越需要后台编排。

## 提示词评分维度

每条提示词至少按 8 个维度评分，总分 100。

| 维度 | 权重 | 评分问题 |
| --- | ---: | --- |
| 任务边界 | 15 | 是否清楚说明要解决什么，不越界、不混乱 |
| 输入变量 | 10 | 是否知道需要用户提供什么、系统继承什么 |
| 输出结构 | 15 | 产物是否稳定，可被产品解析或写入项目 |
| 流程稳定性 | 15 | 是否有步骤、模式、重试和质量门槛 |
| 写作有效性 | 15 | 是否改善冲突、角色、节奏、钩子、正文可读性 |
| 去 AI / 质量护栏 | 10 | 是否降低解释感、模板词、机械收尾和逻辑断点 |
| 可集成性 | 10 | 是否能接入现有 Agent/Skill/流程，而不是只能单次复制 |
| 风险控制 | 10 | 白标清洗、私有化残留、污染、题材过窄、不可验证风险是否低 |

等级：

- `S`：90-100，可作为主版本或核心融合候选。
- `A`：85-89，高价值，优先融合或流程节点。
- `B`：75-84，可用，需要清洗或限定场景。
- `C`：65-74，只适合参考、免费弱能力或补充。
- `D`：65 以下，淘汰或研究-only。

## 产品放置等级

评分之后，再决定放置。

| 放置等级 | 用户感知 | 适合资产 | 例子 |
| --- | --- | --- | --- |
| `core-default` | 默认内置，不让用户选 | 软件质量护栏 | 审稿、去 AI 味、连续性检查、输出格式校验 |
| `agent-guided` | Agent 在需要时调用 | 基础质量工具 | 脑洞、取名、简介、世界观、角色、金手指 |
| `optional-style` | 用户可选择/替换 | 个性化体验 | 作者正文风格、口语推进、锅盖男频、风格 A-F |
| `flow-default` | 选中流程后自动推进 | 作者/平台流程 | 小飞鸡长篇流、天马大纲流、番茄平台流 |
| `premium-enhancement` | 明确付费增强 | 高级稳定性/诊断 | 十章循环、前十章诊断、高级拆书卡、高级主编 |
| `sanitize-required` | 暂不进入用户产品 | 已授权但未白标清洗 | 含作者名、联系方式、个人协议的定制资产 |
| `research-only` | 不进入用户产品 | 污染高、不可验证、或外部来源授权未知 | 白标后仍不可控的资产 |

## 拆书卡评分

拆书卡需要单独评分。原因是：提示词质量高，只能说明“拆书工具”好；拆出来的卡是否能用于当前作品，还要看证据、迁移性和污染风险。

总分 100。

| 维度 | 权重 | 评分问题 |
| --- | ---: | --- |
| 证据覆盖 | 20 | 是否有足够章节/片段支撑，而不是凭空概括 |
| 信号具体度 | 15 | 是否能落到句式、节奏、钩子、动作、对白等可执行层 |
| 可迁移性 | 15 | 是否抽象成方法，而不是复刻原书情节 |
| 污染安全 | 15 | 是否避开原书角色名、地名、能力名、金句和专属桥段 |
| 项目匹配 | 15 | 是否适合当前题材、平台、篇幅、作者偏好 |
| 可叠加性 | 10 | 是否能与 canon、题材包、平台包、流程节点共存 |
| 可验证性 | 10 | 使用后是否能通过审稿、对比试写或用户反馈验证 |

拆书卡放置等级：

- `default-quality-card`：反模式、动作链、主编审稿，默认进入审稿/精修。
- `agent-recommended-card`：节奏、钩子、角色动力，按问题推荐。
- `optional-style-card`：文风、对白、叙述口味，由用户试驾。
- `project-overlay-card`：当前作品临时叠加，不全局保存。
- `saved-skill-card`：用户确认有效后保存到 Skill 仓库。
- `premium-diagnostic-card`：前十章、黄金三章、平台完读诊断。
- `research-only-card`：污染风险高、不可验证、或外部来源授权未知，不进入用户可见产品。

详细方案见：`docs/research/prompt-deconstruction-fusion-system.md`。

## 质量能力 vs 个性化体验

这是后续产品板块重构的核心。

### 1. 软件质量护栏：默认内置

这些能力不应让用户反复选择。它们是软件质量，而不是创作口味。

包括：

- 去 AI 味检测和基础修复。
- 审稿 blocking。
- 设定一致性。
- 时间线/角色状态连续性。
- 输出结构校验。
- 段落可读性和明显病句检查。

处理方式：

- 默认进入 `manualAudit`、`orchestrateCritic`、`buildRewritePrompt`、`slop-scorer`。
- 用户可以调强弱，但不需要挑具体提示词。
- 高级版可以付费，但基础质量线必须免费内置。

### 2. 基础创作质量工具：Agent 引导触发

脑洞、取名、世界观、角色、金手指、大纲不是“体验风格”，而是作品质量的基础材料。

它们不应作为大量模板让用户选，而应该内置到 Agent 的开书和补材料对话里。

包括：

- 灵感/脑洞：用户不知道写什么时触发。
- 取名/简介：开书、发布前、平台适配时触发。
- 世界观：项目缺规则或背景不稳时触发。
- 角色：缺主角动机、配角功能、关系张力时触发。
- 金手指：爽点不清、长篇驱动力不稳时触发。

处理方式：

- 基础版免费内置。
- 高质量定制版可作为流程主节点。
- 不把“取名器/脑洞器/世界观器”堆成工具市场。

### 3. 个性化写作体验：选配

正文写出来像什么，是用户体验和风格偏好。

包括：

- 作者流程中的正文风格。
- 口语化推进。
- 男频/女频正文。
- 第一人称/第三人称。
- 情绪浓度、对白密度、叙述速度。
- 平台强风格，如番茄快节奏、知乎强反转、老福特 CP 兑现。

处理方式：

- 默认推荐一个主路径。
- 用户可试驾、替换、叠加。
- 不作为全局强制质量标准。

### 4. 商业/平台诊断：默认轻量，严格模式选配

平台维度影响质量，但也会改变创作取向，因此不能全局强制。

处理方式：

- 轻量平台建议：默认可提示。
- 严格商业诊断：用户选择平台或开启商业模式后启用。
- 付费价值：前十章完读诊断、付费点诊断、平台适配重写。

## 推荐内置强化链路

### 后置质量链路

优先融合到默认链路：

- 小飞鸡去 AI 高频词 + 润色。
- 锅盖去 AI 润色。
- 风华逻辑检测和审稿思路。
- 番茄合集里的去 AI 味指南。
- webnovel-writer 的 reviewer schema。

落点：

- `slop-scorer`：检测解释感、模板词、机械句式、弱动作。
- `buildRewritePrompt`：输出局部手术补丁，不大改剧情。
- `manualAudit`：可验证问题、证据、修复建议。
- `orchestrateCritic`：blocking 决策，不泛泛评分。

原则：

- 后置链路只做质量护栏，不改变作者文风。
- 修复建议必须保留剧情顺序、设定、悬念落点。
- 可作为默认内置；高级严审作为付费增强。

### 前置质量链路

优先融合到 Agent 引导：

- 脑洞/取名/简介。
- 世界观/角色/金手指。
- 大纲/细纲/章纲。

落点：

- 开书 Agent。
- Book Factory。
- World Bible。
- Chapter Planning。

原则：

- 这些是作品质量基础，不是个性化风格。
- 用户不选提示词，只回答创作问题。
- 产物写入 canon，需要版本和一致性。

### 写作体验链路

保留选配：

- 作者正文风格。
- 平台强风格。
- 拆书文风卡。
- 对话/动作/节奏专项卡。

落点：

- Skill Stack。
- Writing Brief。
- Writer。
- 试驾对比。

原则：

- 可按章节或场景切换。
- 不覆盖 canon。
- 需要解释差异化：为什么切换、切换后会改变什么。

## 功能板块重构

基于以上区分，产品板块建议变为：

| 板块 | 作用 | 提示词放置 |
| --- | --- | --- |
| 开书 Agent | 目标平台、题材、篇幅、脑洞、书名简介 | `agent-guided` |
| 作品架构工坊 | 世界观、角色、金手指、大纲 | `agent-guided` + `flow-default` |
| 章节规划 | 细纲、章纲、写前 brief、钩子 | `flow-default` + `overlay` |
| 正文写作 | 文风、正文、续写、场景表达 | `optional-style` |
| 质量审稿 | 连续性、逻辑、blocking、平台轻诊断 | `core-default` |
| 去 AI 精修 | 模板词、解释感、动作链、对白节拍 | `core-default` + premium |
| 拆书资产 | 文风卡、节奏卡、钩子卡、反模式卡 | `overlay` + premium |
| 流程/资产管家 | 当前挂载、推荐、替换、付费升级 | Agent Orchestrator |

## 如何让别人知道提示词更好

不要只显示一个总分。对用户和内部使用两套展示。

### 内部评分

完整显示：

- 总分。
- 8 个维度分。
- 主产物。
- 控制层。
- 授权状态与白标状态。
- 风险。
- 推荐放置。

### 用户展示

只显示少量可理解标签：

- `稳定输出`
- `适合长篇`
- `去 AI 强`
- `番茄适配`
- `结构更完整`
- `需白标清洗`
- `仅研究参考`

示例：

- 小飞鸡长篇细纲：`S / 适合长篇 / 十章循环 / 付费候选`
- 风华逻辑检测：`A / 审稿增强 / 免费广场可用`
- 锅盖润色：`B / 去 AI 强 / 风格偏男频`
- 未清洗沐殇克苏鲁：`题材强 / 需白标清洗 / 复评后决定是否上架`

## 决策规则

1. **默认内置**：跨题材、低风格污染、能提升质量下限的提示词。
2. **Agent 引导**：作品基础质量工具，如脑洞、取名、世界观、角色。
3. **选配体验**：影响正文味道、叙事口味、平台强风格的提示词。
4. **付费增强**：连续流程、高级诊断、长篇稳定性、私有资产编排。
5. **研究-only**：白标后仍私有化强、污染风险高、不可验证的提示词。

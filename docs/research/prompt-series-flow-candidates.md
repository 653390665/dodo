# Skill Series Flow Candidates

日期：2026-07-03

## 设计结论

作者系列提示词要做成 Skill Series Flow。单条提示词如果内部有多个方向，不直接拆成多个用户可见 Skill，先拆成 Step Variant。

同类资产选择时采用“质量优先但必须白标”：

- 用户已确认购买授权；定制提示词质量明显更高时，白标清洗后优先作为流程主节点。
- 广场提示词做免费入口、试驾、补充节点。
- 未白标清洗的定制提示词只能作为候选，不以原文进入用户可见流程。
- 同一个流程里，作者系列节点优先保持连贯；跨作者替换只发生在步骤边界。

拆分规则：

- **流程步骤**：用户心智上是下一步，例如脑洞、世界观、角色、大纲、细纲、章纲、正文、润色。
- **步骤变体**：同一步内部的不同模式，例如主角/配角、开书/循环、男频/女频、风格 A-F。
- **可替换节点**：允许用户在步骤边界换另一个作者/工具。
- **可叠加卡片**：正文、审稿、精修阶段可以叠加拆书卡、平台卡、文风卡。

## Flow 1：小飞鸡长篇流

定位：高价值付费/定制候选，完整长篇工作流。

来源：

- `private-181` 五个长篇脑洞
- `private-177` 长篇超宏大世界观
- `private-157` 长篇角色卡
- `private-175` 长篇通用大纲
- `private-178` 长篇细纲
- `private-179` 长篇通用章纲
- `private-180` 长篇正文
- `private-193` 正文去 AI 高频词+润色
- `square-183` 长篇拆书器十章版
- `square-176` 长篇正文口语化推进
- `square-174` 番茄长篇正文通用
- `square-182` 爆款书名简介

建议流程：

| 步骤 | 资产 | 输出 | 变体 | 是否可替换 |
| --- | --- | --- | --- | --- |
| 脑洞 | `private-181` | 5 个长篇创意 | 题材/爽点方向 | 可替换为内置灵感或天马脑洞 |
| 书名简介 | `square-182` | 书名、标签、简介、金手指 | 男频/女频公式 | 可替换为通用取名 |
| 世界观 | `private-177` | 世界规则、社会结构、力量体系 | 题材适配 | 可替换但需一致性检查 |
| 角色 | `private-157` | 主角/重要配角/次要配角卡 | 主角/重要配角/次要配角 | 可替换但需同步角色志 |
| 总纲 | `private-175` | 长篇大纲 | 起承转合/爽点组织 | 可替换为天马三幕式 |
| 十章细纲 | `private-178` | 前十章或十章循环 | 开书模式/循环模式 | 不建议中途换 |
| 单章章纲 | `private-179` | 6-8 场景、15-20 剧情点 | 爽点类型/钩子类型 | 可替换为内置分镜 |
| 正文 | `private-180` / `square-176` / `square-174` | 章节正文 | 风格 A-F、番茄正文、口语推进 | 可按章试驾切换 |
| 拆书校准 | `square-183` | 前十章拆解卡 | 黄金三章/十章节奏 | 可作为叠加诊断 |
| 去 AI 味 | `private-193` | 精修稿 | 禁词/句式/动作化 | 可替换或叠加锅盖/风华润色 |

商业建议：

- 免费入口：书名简介、广场正文、长篇拆书器。
- 付费核心：完整长篇流 + 十章循环 + 去 AI 味。
- 不能卖“提示词文本”，卖“长篇开书到章节生产流程”。
- 因可用定制节点质量高于同类广场节点，小飞鸡长篇流应以定制节点为主版本，广场节点做入口和补充。

## Flow 2：小飞鸡知乎短篇流

定位：短篇/知乎付费点流程，适合免费试用或低价包。

来源：

- `square-107` 短篇第一步：词条+脑洞
- `square-108` 短篇第二步：大纲
- `square-109` 短篇第三步：书名+简介+导语+正文+金句

流程：

| 步骤 | 输出 | 关键规则 |
| --- | --- | --- |
| 词条脑洞 | 爆点词条、故事梗概 | 冲击力、反常识、猎奇 |
| 短篇大纲 | 付费前/付费后结构 | 付费点前情绪和悬念堆叠 |
| 正文直出 | 标题、简介、导语、正文、金句 | 强导语、快节奏、强反转 |

变体：

- 平台变体：知乎短篇 / 番茄短篇。
- 题材变体：都市、情感、穿越、校园等。

商业建议：

- 基础版可免费，作为短篇体验入口。
- 付费点在高级诊断：标题导语、付费点、反转压缩。

## Flow 3：风华短篇 / 老福特流

定位：流程价值高，用户已确认购买授权；第一阶段应优先做白标清洗和短篇/老福特流程还原。

公开可用节点：

- `square-79` / `square-88` / `square-93` / `square-94` 拆爆款并生成脑洞
- `square-80` 世界观生成器
- `square-81` 卷纲
- `square-82` 15 章大纲
- `square-103` 章节梗概
- `square-122` 逻辑检测
- `square-78` 润色降 AI 1.0
- `square-74` 通用正文

私有研究节点：

- `private-124` 老福特脑洞
- `private-125`-`private-128` 老福特大纲变体
- `private-129` 老福特正文
- `private-162` 老福特编辑审稿
- `private-100` / `private-101` 金牌主编审稿/改稿
- `private-85` 对话情绪拉扯
- `private-86` 润色降 AI 2.0

建议流程：

| 步骤 | 处理 |
| --- | --- |
| 爆款拆解 | 公共节点可融合到拆书 Agent |
| 世界观/卷纲/15章大纲 | 可做风华公开流程入口 |
| 短篇/老福特专项 | 私有节点只研究，不直用 |
| 审稿/改稿 | 提炼为通用主编 Agent 维度 |

商业建议：

- 暂不作为付费作者流。
- 先做免费公开流程入口 + 通用审稿增强。

## Flow 4：天马大纲流

定位：免费结构规划流，适合替换小飞鸡大纲节点。

来源：

- `square-38` 基础大纲
- `square-39` 三幕式
- `square-41` 设定强化+节奏
- `square-42` 通用章节大纲
- `square-76` 番茄爆款脑洞
- `square-43` 番茄短篇清澈版

流程：

| 步骤 | 输出 | 用法 |
| --- | --- | --- |
| 基础大纲 | 核心故事骨架 | 免费结构工具 |
| 三幕式 | 起承转合/三幕结构 | 可替换长篇总纲 |
| 设定强化+节奏 | 强化设定与章节节奏 | 可叠加 |
| 章节大纲 | 单章规划 | 可替换内置分镜 |

商业建议：

- 作为免费结构流，服务广场入口。
- 付费不适合单卖，适合作为高级流程里的可替换节点。

## Flow 5：番茄平台流

定位：平台维度，不是作者风格。

来源：

- 番茄合集：评分卡、钩子 13 式、章首 7 式、爽点公式、黄金三章诊断。
- `square-174` 番茄长篇正文通用。
- `square-76` 天马番茄脑洞。
- `square-27` 番茄金手指。
- `private-169` / `private-170` 番茄保底类仅研究。

流程：

| 步骤 | 强化点 |
| --- | --- |
| 开书 | 平台适配、题材匹配、标题简介 |
| 大纲 | 爽点密度、升级/反转节奏 |
| 前三章 | 黄金三章诊断 |
| 单章 | 章首章末钩子、短段落、高信息密度 |
| 审稿 | 完读、追读、爽点兑现 |
| 精修 | 去 AI 味、少解释、强动作链 |

商业建议：

- 基础番茄建议免费。
- 高级番茄诊断和前十章完读评估可付费。

## Flow 6：webnovel-writer 内部 Agent 流

定位：不作为用户可见作者流，作为 InkFlow 内部架构升级。

来源：

- `context-agent.md`
- `reviewer.md`
- `review-schema.md`
- `deconstruction-agent.md`
- `data-agent.md`
- `genre-profiles.md`
- `core-constraints.md`

内部流程：

| 步骤 | Agent | 作用 |
| --- | --- | --- |
| 写前 | Context Agent | 生成 5 段写作 brief |
| 正文后 | Reviewer | 输出可验证问题和 blocking |
| 提交 | Data Agent | 抽取状态变化、承接点、伏笔 |
| 拆书 | Deconstruction Agent | 只提炼可迁移模式，不污染 canon |
| 题材 | Genre Profiles | 作为 fallback 约束 |

商业建议：

- 基础审稿免费。
- 长篇稳定性、章节 commit、前十章诊断可作为高级能力。

## 切换策略总表

| 切换位置 | 允许程度 | 例子 |
| --- | --- | --- |
| 开书前 | 高 | 小飞鸡长篇 -> 天马大纲流 |
| 世界观后 | 中 | 保留小飞鸡世界观，改用天马三幕式 |
| 大纲后 | 中 | 保留大纲，切换风华章节梗概 |
| 章纲后 | 高 | 正文改用锅盖男频或小飞鸡口语推进 |
| 正文后 | 高 | 审稿用风华逻辑检测，润色用小飞鸡去 AI |
| canon 写入后重改 | 低 | 必须版本化和一致性检查 |

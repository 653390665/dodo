# Prompt Skill Taxonomy

日期：2026-07-03

## 核心判断

提示词资产不能都叫“作者流派”，也不能都挂成同一种 Skill。它们至少分为七类，每类的使用流程、交互位置、是否付费、是否挂载都不同。

## 分类总表

| 类型 | 本质 | 是否影响文风 | 挂载位置 | 例子 |
| --- | --- | --- | --- | --- |
| 写作风格流派 Skill | 改变正文味道、句式、节奏、对白、动作链 | 是 | 项目/章节写作阶段 | 口语化推进、男频正文、去 AI 味文风 |
| 功能工具 Skill | 完成一个明确创作任务 | 否或很弱 | 按任务临时调用 | 小说命名、脑洞、角色生成、世界观、简介 |
| 通用主编 Skill / Agent | 做审稿、改稿、质量判断 | 不直接改变 | 审稿/精修阶段 | 金牌主编审稿、逻辑检测、黄金手术刀 |
| 题材/格式包 | 规定题材规则、平台格式、读者预期 | 间接影响 | 项目级 | 玄幻、克苏鲁、宝可梦、知乎短篇、老福特 |
| 发布平台维度 | 选择发布环境、商业规则、读者消费习惯 | 间接影响 | 开书前/项目级 | 番茄、起点、晋江、知乎、老福特、七猫、飞卢 |
| 作者流程包 | 同一作者/方法论的连续工序 | 可能影响 | 流程级 | 小飞鸡长篇流、风华短篇流、天马大纲流 |
| Agent 设定/职责强化 | 强化 Agent 的判断口径和引导话术 | 不作为用户文风 | Agent 内部 | 开书策划、主编审稿、资产管家 |
| 拆书能力卡 | 从参考文本抽象出的可迁移能力 | 可能影响 | 章纲/正文/审稿叠加 | 文风卡、节奏卡、钩子卡、角色动力卡 |

## 主归属 + 次归属

同一个功能名不能决定最终归类。比如“世界观生成”可能是通用功能工具，也可能是某作者流程包的一环，还可能是题材包的一部分。

每条资产必须同时标注：

- **主归属**：产品里优先以什么形态出现。
- **次归属**：可被复用到哪里。
- **调用边界**：什么时候用它，什么时候不用。

### 判断优先级

1. **是否是连续流程的一环？** 如果它和同作者前后步骤强绑定，主归属为 Author Flow Pack。
2. **是否绑定发布平台？** 如果强绑定平台商业规则、章节节奏、读者预期，主归属为 Platform Dimension。
3. **是否绑定特定题材/语言/格式？** 如果强绑定，主归属为 Genre / Format Pack。
4. **是否可跨题材单独完成任务？** 如果可以，主归属为 Functional Tool Skill。
5. **是否主要是判断标准？** 如果是，主归属为 Editor/Agent Enhancement。
6. **是否改变正文口味？** 如果是，主归属为 Writing Style Skill。

次归属允许复用，但交互里只显示主归属，避免用户困惑。

## 1. 写作风格流派 Skill

### 定义

影响“写出来像什么”的资产。它作用于正文生成、续写、改写、润色。

### 判断标准

- 是否影响句式、对白、动作链、叙事密度、节奏。
- 是否会让同一个剧情写出不同味道。
- 是否不适合全局默认。

### 例子

- 【小飞鸡】长篇正文~超强口语化推进剧情
- 锅盖男频正文直出《灵光版》
- 【小飞鸡】正文去AI高频词+润色
- 【风华出品】超强文风自适应续写

### 交互方式

- 开书或项目设置时可选择“偏哪种写法”。
- 正文质量不稳定时由 Agent 推荐挂载或替换。
- 不应在每次生成前让用户手动选。

## 2. 功能工具 Skill

### 定义

完成一个具体创作任务的工具，不代表作者风格，也不一定长期挂载。

### 判断标准

- 用户目标是“帮我做一件事”，不是“让整本书像某种风格”。
- 输出是一个可用结果：名字、脑洞、角色卡、简介、事件、世界观条目。
- 任务完成后可以退出，不需要持续影响后续全部生成。
- 如果这个工具属于某作者完整流程的一环，默认主归属仍是流程包节点；只有抽出通用版后才作为通用功能工具独立展示。

### 例子

- 小说命名：小说起名器、爆款书名简介策划引擎
- 灵感脑洞：五个长篇脑洞、脑洞生成、融梗换心
- 角色生成：生成角色、新角色、主角/配角信息卡
- 世界观生成：世界观生成器、世界观生成专家
- 简介生成：简介、书名与简介
- 事件生成、金手指生成

### 交互方式

- 放在“补材料”“生成资产”的工具入口。
- 由 Agent 在缺口明确时推荐：比如“现在缺主角动机，是否生成角色卡？”
- 可以挂成 Skill，但默认是临时工具；只有用户确认“持续影响项目”时才项目级挂载。

## 3. 通用主编 Skill / Agent

### 定义

审稿、改稿、逻辑检测、商业判断、去 AI 味问题定位属于通用主编能力。它们不是文风流派。

### 判断标准

- 换题材后仍有用。
- 输出是问题、评分、建议、改稿方案。
- 主要作用是判断和修正，不是决定整本文风。

### 例子

- 金牌主编审稿
- 金牌主编改稿
- 短篇文章逻辑检测分析器
- 老福特编辑审稿
- 黄金手术刀

### 交互方式

- 默认内置基础审稿 Agent。
- 外部审稿提示词用于强化审稿维度：逻辑、追读、商业、题材一致性、去 AI 味。
- 审稿结果可以触发改稿工具，但不直接改写文风。
- 付费包装应叫“高级主编审稿 Agent”或“商业审稿增强”，不是“某作者风格”。

## 4. 题材/格式包

### 定义

影响“写什么类型、遵守什么读者预期”的资产。它不等于文风。

### 判断标准

- 是否绑定题材规则、世界观结构、平台格式。
- 是否主要影响设定、角色、冲突、钩子，而不是句子口味。

### 例子

- 玄幻、修真、都市异能、重生、快穿、末世、悬疑推理
- 老福特、知乎短篇、番茄长篇、七猫保底、飞卢爽文
- 克苏鲁、宝可梦等强题材定制

### 交互方式

- 开书时选择或由系统识别。
- 一本书通常只挂 1-2 个主题材/格式包。
- 强题材包应影响世界观、角色、章纲、正文，不只影响 prompt 文本。

## 5. 发布平台维度

### 定义

发布平台维度回答“这本书准备在哪里发”。它不是题材，也不是文风，而是商业环境和交付规则。

### 判断标准

- 是否影响章节长度、更新节奏、开篇钩子、爽点密度、付费节点、简介书名。
- 是否影响审稿重点：完读、追读、收藏、付费、互动、同人接受度。
- 是否要求平台专属禁区或格式：番茄长篇、起点男频、晋江感情线、知乎短篇、老福特同人、七猫保底、飞卢爽文。

### 例子

- 番茄：快节奏、高频钩子、情绪密度、短段落、完读导向。
- 起点：世界观纵深、升级体系、长期爽点和副本结构。
- 晋江：人物关系、情感推进、设定标签和文案承诺。
- 知乎：强开头、强反转、短篇压缩、标题导语。
- 老福特：CP/同人语境、圈层读者预期、角色关系兑现。
- 七猫/飞卢：保底/爽点/更新与题材强约束。

### 交互方式

- 开书前由 Agent 询问或识别，不强制用户先选。
- 如果用户不确定，系统用“目标读者 + 篇幅 + 变现方式 + 文风偏好”推荐平台。
- 平台维度会影响题材包、流程包、审稿维度和章节规划，但不能覆盖用户的项目设定。
- 同一作品可以有主平台和备选平台；主平台决定默认诊断，备选平台只给差异提醒。

### 与题材/文风/作者流程的区别

| 维度 | 回答的问题 | 例子 |
| --- | --- | --- |
| 题材 | 写什么世界和冲突 | 玄幻、言情、悬疑、克苏鲁 |
| 文风 | 怎么写句子和场景 | 口语化推进、克制冷感、第一人称 |
| 平台 | 发在哪里、按什么规则竞争 | 番茄、起点、晋江、知乎 |
| 作者流程 | 用哪套连续工序推进 | 小飞鸡长篇流、风华短篇流 |

## 6. 作者流程包

### 定义

同一作者或同一方法论下的一组连续提示词。它是流程，不是单卡。

### 判断标准

- 是否覆盖多个创作阶段。
- 是否有明确顺序。
- 是否同一作者/团队的提示词彼此配套。

### 例子

- 小飞鸡长篇流：脑洞 -> 世界观 -> 角色 -> 大纲 -> 细纲 -> 章纲 -> 正文 -> 去 AI 味
- 风华短篇流：拆爆款/脑洞 -> 大纲 -> 正文/导语 -> 审稿 -> 改稿
- 天马大纲流：基础大纲 -> 三幕式 -> 设定强化+节奏 -> 通用章节大纲
- 沐殇题材定制流：宝可梦/克苏鲁世界观 -> 角色 -> 章纲 -> 正文 -> 标题简介

### 交互方式

- 用户选择“用这套创作流程”，而不是一条条选 prompt。
- Agent 负责在每个阶段调用流程包里的对应资产。
- 可以作为付费包，但价值是连续流程和稳定结果，不是单条提示词文本。

## 7. Agent 设定/职责强化

### 定义

强化 Agent 的角色、判断标准和引导话术。用户不直接挂载为写作风格。

### 判断标准

- 是否是“你是一位金牌主编/策划/提示词工程师”这类角色设定。
- 是否主要改变 Agent 的评价标准、推荐逻辑、提问方式。
- 是否适合隐藏在流程内部。

### 例子

- 金牌主编：强化审稿 Agent。
- 开书策划：强化灵感/方向卡 Agent。
- 资产管家：解释当前挂载资产、推荐替换。
- 结构规划师：管理剧情点预算、伏笔消耗。

## 8. 拆书能力卡

### 定义

拆书能力卡是从参考文本中抽出的可迁移写作能力，不是原作内容。

### 可拆内容

- 文风卡：句式、语气、叙述密度、对白比例。
- 节奏卡：推进速度、信息释放、爆点间隔。
- 钩子卡：章首、章末、付费点、悬念类型。
- 角色动力卡：欲望、压力、关系拉扯。
- 爽点循环卡：铺垫、释放、反应、承接。
- 世界规则模式卡：抽象规则、限制、代价。
- 反模式卡：容易写崩的套路和禁区。

### 不可拆内容

- 原作角色、地名、组织、能力名。
- 具体剧情事实。
- 名场面和金句。
- 强私有化提示词的专属约束。

### 叠加方式

- 架构层：只叠加抽象结构，如世界规则模式、角色动力模式。
- 写作层：可叠加文风、节奏、钩子、去 AI 味。
- 审稿层：叠加反模式和平台诊断。

## 分类决策规则

### A. 小说命名、脑洞、角色生成怎么归类？

归为 **功能工具 Skill**。

原因：

- 它们完成具体任务。
- 不应改变整本书的文风。
- 可以临时调用，也可以把结果写入项目设定。

### B. 审稿怎么归类？

归为 **通用主编 Skill / Agent**。

原因：

- 它是跨题材通用判断能力。
- 可以被题材包或商业维度增强。
- 不应该挂成“某种写作风格”。

### C. 正文、续写、润色怎么归类？

看它影响什么：

- 如果影响句式和叙事口味：写作风格流派 Skill。
- 如果只是修问题：通用主编/改稿 Skill。
- 如果是流程中的一步：作者流程包节点。

### D. 大纲、章纲、细纲怎么归类？

可能是三种：

- 单点生成大纲：功能工具 Skill。
- 十章循环/剧情点预算：流程强化包。
- 某作者完整开书链路的一环：作者流程包节点。

### E. 题材强绑定资产怎么归类？

归为 **题材/格式包**。

例如克苏鲁、宝可梦、老福特、知乎短篇，它们需要影响世界观、角色、章纲、正文和审稿，而不是单条正文 prompt。

### F. 世界观生成怎么归类？

不能只看 `worldview` 分类，要看上下文。

| 资产类型 | 主归属 | 次归属 | 理由 |
| --- | --- | --- | --- |
| 小飞鸡长篇超宏大世界观 | 作者流程包节点 | 可抽出通用世界观工具 | 与小飞鸡长篇脑洞/角色/大纲/细纲/正文成套，但其结构也足够通用 |
| 风华世界观生成器（第二步） | 作者/平台流程包节点 | 不直接通用 | 明确是第二步，依赖脑洞和金手指，且含私密提示污染 |
| lwl 世界观生成 | 题材功能工具 | 可作为二次元变身入替题材包 | 强绑定二次元 + 变身入替，不是通用世界观 |
| fire 定制世界观 | 题材/语言格式包 | 不通用展示 | 绑定英文爽文和 Urban Fantasy/Cultivation/LitRPG 等格式 |

产品处理：

- 先保留原流程节点，不拆散。
- 再评估是否能抽出“通用世界观生成 Skill”。
- 抽出通用版时必须去掉作者私有链路、平台癖好、联系方式、自保护协议。
- 用户交互上，默认看到“补世界观”功能；若已选择某作者流程，则系统优先调用该流程内的世界观节点。

### G. 雷同提示词怎么处理？

同类提示词很多时，不按名字去重，而按“方法差异”去重。

保留维度：

- 输出结构不同：短世界观、长世界观、力量体系、地图势力、题材规则。
- 适用场景不同：开书、续写补设定、前十章诊断、题材定制。
- 方法论不同：自洽规则、爽点服务、二次元机制、英文适配。
- 白标状态与污染不同：可直接候选、需清洗候选、只可结构融合、必须拒绝。

合并方式：

- 相同任务但方法互补：融合成通用工具的不同模式。
- 同作者连续步骤：保留流程包，不拆成散件去重。
- 强题材资产：归入题材包，不和通用工具硬合并。

## 对产品交互的影响

### 开书页

展示：

- 题材/格式推荐
- 作者流程包推荐
- 功能工具：命名、脑洞、角色、世界观

不展示：

- 全部 prompt 列表
- 审稿增强
- 复杂 Agent 设置

### 章节页

展示：

- 当前章节可用的风格流派 Skill
- 细纲/章纲/剧情点预算工具
- 正文/续写工具

不展示：

- 与当前章节无关的命名/开书工具

### 审稿页

展示：

- 通用主编 Agent
- 逻辑/追读/商业/去 AI 味检查维度
- 改稿工具

不展示：

- 把审稿当作文风流派

### 资产库

需要按分类浏览：

- 作者流程包
- 题材/格式包
- 写作风格 Skill
- 功能工具
- 主编审稿/改稿
- Agent 强化

## 免费 / 付费影响

免费适合：

- 基础功能工具
- 基础审稿
- 广场高质量单点 Skill
- 流程包试用节点

付费适合：

- 完整作者流程包
- 高级主编审稿 Agent
- 强题材格式包
- 经过验证的风格流派 Skill

不适合付费：

- 单条未经验证的 prompt
- 未白标清洗的原始定制资产
- 只靠神秘感包装的提示词

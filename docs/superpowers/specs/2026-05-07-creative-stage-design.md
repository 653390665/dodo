# 创作舞台重排设计

## 目标

把“创作舞台”从空白占位页改成高密度、可立即开始工作的写作工作台，让用户一进页面就能同时看到：

- 当前章节与文档编辑器
- AI 智能管家入口与关键工作流
- 世界观/技能/保存状态等上下文

## 布局方案

采用固定三段式工作台：

- 左侧：章节与卷导航，保持现有结构
- 中间：主文档编辑区，成为唯一视觉主角
- 右侧：默认展开的智能管家工作台，承载灵感、分镜、审计、伏笔、设定等面板

## 关键调整

### 中间主编辑区

- 顶部工具栏保留章节元信息，但压缩成更紧凑的标题区
- 空内容时不再用大面积留白，而是在编辑器顶部内嵌“开始创作”欢迎层
- 欢迎层同时提供：
  - 直接开始书写
  - 唤醒智能管家
  - 快速生成分镜
- 文本编辑器始终可见，占据主要高度

### 右侧智能管家

- 默认展开，不再要求用户先点机器人按钮才看见
- 保持标签页结构，但首屏默认展示高价值入口
- 面板宽度略增，让“灵感 / 分镜 / 审计 / 设定”内容可读

### 底部与状态信息

- 把“世界观已就位 / 挂载技能 / token / AI 连接 / 导出”从独立底栏提升进主工具栏
- 底栏只保留写作直接相关信息：字数、更新时间、保存状态

## 视觉原则

- 减少空白装饰，增加可操作模块
- 中间编辑器用更强的卡片层级和留白
- 智能管家用浅色面板与主编辑器区分
- 保持现有品牌和配色，不重做设计系统

## 验收标准

- 首屏不再出现大面积无功能空白
- 用户无需额外点击即可看到智能管家
- 文档编辑器在空内容和有内容两种状态下都保持主舞台地位
- 页面在当前浏览器宽度下功能模块可见且不显拥挤

# 设定与续写导航升级设计

日期：2026-05-25

## 目标

把当前左侧导航中的 `世界设定集` 从偏知识库的入口，升级为更符合用户任务心智的 `设定与续写`。

这次不新增独立一级 `资料续写` 导航，而是在同一个入口里：

- 把 `资料续写总览` 提升为默认首屏
- 把 `世界设定 / 人物 / 地点 / 道具 / 势力 / 时间线` 保留为二级内容
- 让用户一进入就知道：
  - 当前有没有可用资料包
  - 当前处于待审核还是可续写状态
  - 下一步应该导入、审核，还是直接开始续写

## 非目标

- 不重做整套 `World Bible` 数据模型
- 不拆出新的一级侧边栏入口 `资料续写`
- 不修改现有资料包解析、批准、自动生产的后端协议
- 不在总览页放大型可编辑表单

## 用户问题

当前 `世界设定集` 入口更像“维护资料库”，不够像“启动续写任务”。

这导致两个问题：

1. 用户不知道这条链路的主动作在哪里
2. 即使资料包已经解析或批准，也看不到“现在能不能开始续写”

## 设计原则

1. 导航层先合，不先拆
   - 左侧不增加新的一级 `资料续写`
   - 先在现有设定入口里完成任务化升级

2. 首页先看状态，不先看表单
   - 默认首屏是 `资料续写总览`
   - 先回答“能不能写”和“下一步做什么”

3. 管理和执行分层
   - 总览页负责状态、决策、跳转
   - 设定子页负责编辑和资产管理

## 信息架构

### 左侧导航

将 `世界设定集` 改名为：

- 推荐：`设定与续写`
- 不推荐：保留 `世界设定集`

采用推荐命名，原因是左侧导航需要短、清楚、偏动作，不需要像文档标题。

### 入口内的二级结构

进入 `设定与续写` 后，页面二级结构调整为：

1. `总览`
2. `资料包管理`
3. `世界设定`
4. `人物档案`
5. `地点副本`
6. `道具设定`
7. `势力 / 力量体系`
8. `纪元与时间线`

说明：

- `总览` 为默认首屏
- `资料包管理` 前置到第二位，因为它和续写主线最相关
- 其余内容继续保留，承担资产维护职责

## 总览页设计

总览页目标：用户一进来就知道 `当前状态 / 任务摘要 / 风险 / 下一步动作`。

总览页按从上到下 4 个区块组织。

### 1. 当前续写状态

展示：

- 当前资料包：`未接入 / 已接入 <pack title>`
- 状态：`待审核 / 已确认 / 有风险`
- 最近更新时间
- 模式提示：`本次自动生产将默认使用该资料包`

这是首屏最高优先级信息，用来确认“系统到底有没有接上资料包”。

### 2. 本次续写任务

展示：

- 续写任务一句话摘要
- 当前剧情锚点
- 即时冲突
- 下一步建议

这是主内容区，直接服务于“接下来写什么”。

### 3. 风险与缺口

展示：

- 资料冲突数量
- 审读问题数量
- 续写缺口数量
- 最重要的 1 到 2 条提示

这里只给摘要，不展开成大列表。

### 4. 主动作区

总览页只保留 3 个固定动作：

- `导入资料`
- `审核资料包`
- `开始按资料续写`

按钮优先级由状态驱动：

- 有 `approved` pack 时：主按钮是 `开始按资料续写`
- 有 `draft` pack 待审核时：主按钮是 `审核资料包`
- 没有 pack 时：主按钮是 `导入资料`

## 状态规则

### 状态 A：没有资料包

展示：

- `未接入资料包`
- 说明：还没有可用于续写的资料，请先导入世界观、大纲、任务或已有正文

动作：

- 主按钮：`导入资料`
- 次按钮：`查看世界设定`

跳转：

- `导入资料` -> 导入 flow
- 不自动跳编辑器

### 状态 B：有 draft 资料包，待审核

展示：

- `已解析，待审核`
- 资料包标题、来源文件数、更新时间
- 摘要：续写任务、剧情锚点、主要风险

动作：

- 主按钮：`审核资料包`
- 次按钮：`重新导入资料`

跳转：

- `审核资料包` -> 资料包确认页
- 审核通过后返回总览，状态升级为 C
- 不自动跳编辑器

### 状态 C：有 approved 资料包，可开始续写

展示：

- `已接入资料包`
- 当前启用 pack 名称
- 续写任务、剧情锚点、即时冲突、下一步建议

动作：

- 主按钮：`开始按资料续写`
- 次按钮：`更换资料包`
- 辅助入口：`进入资料包管理`

跳转：

- `开始按资料续写` -> 进入编辑器，自动打开生产面板，并默认选中当前 approved pack
- `更换资料包` -> 资料包管理或导入页

### 状态 D：有 approved 资料包，但存在明显风险

展示：

- `可续写，但有风险`
- 风险摘要：冲突数、缺口数、最严重 1 条问题

动作：

- 主按钮：`先处理风险`
- 次按钮：`仍然开始续写`

跳转：

- `先处理风险` -> 资料包管理 / 审核页
- `仍然开始续写` -> 编辑器生产面板，并显示风险提示

### 默认优先级

总览页打开时按以下优先级判断主状态：

1. 有 `draft` -> 优先提示审核
2. 没有 `draft`，但有 `approved` -> 主推开始续写
3. 两者都没有 -> 主推导入资料

即：`待确认优先于可使用，可使用优先于空状态`。

## 交互约束

1. 总览页不承载大型可编辑表单
2. 总览页不展示冗长资料明细
3. 主按钮文案语义固定，不随产品文案频繁变化
4. “开始按资料续写” 只能出现在已经有可用资料包的状态下

## 现有页面职责调整

### 设定与续写总览

负责：

- 看当前状态
- 识别风险
- 进入导入、审核、生产动作

### 资料包管理

负责：

- 查看资料包历史
- 删除资料包
- 手动切换 pack
- 回看解析结果
- 处理冲突

### 世界设定 / 人物 / 地点等子页

负责：

- 维护长期资产
- 为后续续写补充信息

## 最小实现范围

本轮只做最小导航升级，不做大重构。

包含：

1. 左侧导航文案从 `世界设定集` 改为 `设定与续写`
2. `World Bible` 页面新增默认首屏 `总览`
3. 原 `资料续写` 内容拆分成：
   - 总览页上的摘要与动作
   - 二级 `资料包管理` 页上的管理能力
4. 保留现有世界设定、人设、地点等数据编辑页

不包含：

1. 新增独立左侧一级导航 `资料续写`
2. 重写资料包解析协议
3. 重做编辑器生产面板

## 验收标准

满足以下条件即认为设计落地正确：

1. 用户从左侧点击 `设定与续写` 后，默认看到的是 `总览`，不是表单页
2. 用户可以在总览首屏直接判断当前是导入、审核还是开始续写
3. 有 approved pack 时，用户可以从总览一跳进入编辑器生产面板
4. 世界设定、人设、地点等旧能力仍然可达，不丢失

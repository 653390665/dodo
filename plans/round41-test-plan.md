# Round 41 全链路独立测试计划

三组子代理从零开始，不信任此前结论。每组独立建测试小说，走完全部步骤，报告所有发现。

## 组A：创作管线全链路

| 步骤 | 测试项 | 验证要点 |
|------|--------|----------|
| A1 | 建书 + 创建第一章 | 建书成功→自动进编辑器→章节标题正确 |
| A2 | 世界观/设定集 | 设定页签→创建世界观/人物→保存→返回查看 |
| A3 | 大纲生成 | 通过流程引导或智能管家生成大纲→产出是否引用设定 |
| A4 | 章纲→细纲 | 生成章纲细纲→是否引用大纲与世界观 |
| A5 | 分镜生成 | 生成分镜→钩子/冲突/伏笔/黄金三章结构 |
| A6 | 正文→审稿→接受→完成 | 生成→内审→接受→DB/编辑器/回执 |
| A7 | 联动一致性 | 正文引用设定？细纲被消费？文风匹配世界观？ |
